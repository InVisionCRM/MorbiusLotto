How it pays

The token flows down 8 gates. Each gate multiplies your running total by its value — but a gate can drain (the river falls away) and you lose. Survive all eight and you keep the full multiplier. No cash-out: it's a watch-it-flow drop. Wilder currents drain more often but pay far bigger.

Prototype — Deep-Sea Neon style, single-player on the arcade2 pattern (Plinko-family).
Each gate is drawn from an in-page seeded RNG for feel; the real build derives the stream from the server provably-fair HMAC pipeline (/api/arcade/splitstream/*). The descent is a deterministic function of the seed, so it re-runs exactly in Verify. RTP fixed by the drain rate × segment table. Currency: MORBIUS chips.
