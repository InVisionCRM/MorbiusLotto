Prototype — Deep-Sea Neon style. This demo simulates a live room: the other players are scripted sea-bots and chat is canned, so one browser can feel the whole loop. The real build runs rooms, chat, buy-ins and payouts on MORBlotto's existing WebSocket multiplayer / tournament backend, and the 75-ball draw order derives from the server provably-fair commit/reveal pipeline. Currency: MORBIUS.

Provably Fair

Your client seed

Mixed into every round's draw order. Change it any time — the next round uses the new value.

Verify a round

Before each round the server commits to a secret server seed (you see only its SHA-256 hash). The full 75-ball draw order derives from a seeded Fisher–Yates shuffle of (serverSeed : clientSeed : nonce) — fixed before the first ball, revealed at settlement, so anyone can replay the whole draw.
