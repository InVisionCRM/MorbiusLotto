Prototype — Deep-Sea Neon style, single-player on the arcade2 pattern (like Mines / Chicken / Cipher).
Every gem here is dealt by an in-page seeded RNG for feel; the real build derives the stream from the server provably-fair HMAC pipeline (/api/arcade/cascade/*) and tunes the weights / paytable to the target RTP. The whole cascade is a deterministic function of the seed, so it re-runs exactly in Verify. Currency: MORBIUS chips.
