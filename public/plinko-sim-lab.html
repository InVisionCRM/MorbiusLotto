M Plinko Prototype — Path-Driven · Variable Rows

A working prototype of the proposed architecture: the ball follows a predetermined left/right path (what the provably-fair server would send) and is animated straight into that bucket — no seed database. Rows are fully variable (8–16), and each row count has its own multiplier table tuned to ~97% RTP.
What this proves: ① rows change instantly with no re-bake, ② the ball always lands in the path's bucket (visual = payout, 100% integrity), ③ the resulting distribution is binomial so RTP holds per row count. The path here is generated client-side to mimic the server; in production the server sends it. Multiplier tables are auto-generated prototype values (finalize before launch). Bounce here is animation juice, not a physics sim — so it's free to tune and needs no bake.
