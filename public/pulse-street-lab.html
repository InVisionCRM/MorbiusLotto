Verify a round

Every spin draws, in fixed order: 5 reel stops → one multiplier per wild (reel-major) → the Bull Run entry draw (enter? then a free-cell pick, free spins only) → the whole Vault Run if 3 PUMP coins hit (per respin: a land/no-land uniform per empty cell, then each landed cell's type + value + special randoms) — all from one stream derived from a server seed committed (hashed) before your bet. Sticky bulls lock in place and replay exactly; the Vault Run is fully pre-resolved. Jackpot hits are re-checked from the wild count; pool sizes are account state.
