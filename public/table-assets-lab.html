TABLE ASSETS — the starting library

What a creator would pick from. Every swatch is procedural — nothing was drawn, and each one is a handful of numbers the renderer already reads, so the library costs authoring time rather than art budget. Anything that genuinely wants a bitmap later (a carved wood, a real leather scan) drops into the same slot as an image layer without the model changing.

Felts

A felt is { from, to, edge } — centre, body and the deepest tone at the rim. Grain is a separate layer, shown over each.

Rails

A rail is { from, to, sheen } plus the seam that follows it. Shown as a slice of the padded surround.

Trims

The hard line where rail meets felt — { color, thickness, glow }. Small, but it's what makes a table read as finished.

Cloth grain

One number: how fine the weave is. The only part flat gradients genuinely cannot fake.

Lighting

The pass that seats everything in one room — { key, keySpread, vignette }.

Mixed — same table, four dressings

Each is the identical layer stack with different values in it. No new art was made for any of them.
