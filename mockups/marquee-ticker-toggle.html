How state 2 gets its data:
  • Fetch /api/blackjack/tables?enabledOnly=true once on marquee mount. Returns ~25 rows from the blackjack_tables table — same endpoint the Featured tab in the sponsor modal already uses, so no new API.
  • Filter out rows where ticker or token_contract_address is NULL (user noted some entries don't have tickers). Result: the subset that can show real market data.
  • For each remaining token, call fetchDexScreenerTokenInfo(address) in parallel (Promise.allSettled so one slow/missing token doesn't block the rest). Use the existing helper from lib/dexscreener-token-info.ts; priceUsd + priceChangeH24 are already parsed there. Cache the result in module state and refresh on a ~60s interval.
  • Render the ticker tape using the same animate-poker-marquee CSS already in the project; just swap the children when the toggle flips.
Toggle behaviour:
  • Two icon buttons in a pill at the far right of the marquee — separated from the scrolling content by a thin border so they're never hidden by the mask gradient.
  • Active button gets cyan fill + outline. Clicking the inactive one switches state, persists the choice to localStorage under a key like pokerMarqueeMode so it survives page reloads.
  • Defaults to sponsor view on first visit (preserves current behaviour). Players who prefer market view get it sticky after one tap.
